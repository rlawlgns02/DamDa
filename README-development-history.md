# DamDa

상황에 맞는 정보만 담아 공유하는 디지털 명함 웹 앱입니다.

## 실행

처음에는 `npm install`, 이후 `npm start`를 실행하고 터미널에 표시되는 주소로 접속합니다. 기본 포트는 5173이며 이미 사용 중이면 다음 포트를 사용합니다.

체험 로그인: **admin / 1234**

로그인, 3단계 회원가입, 정보 공개 선택, 사용자 정의 항목, 프로필 사진, 프리셋, 3가지 명함 디자인, 공유 링크와 QR 코드를 제공합니다. 모바일 레이아웃과 움직임 줄이기 설정을 지원합니다.

실제 인증 서버 없이 동작합니다. 가입은 온보딩 체험이며 비밀번호는 저장하지 않습니다. 프로필과 로그인 상태는 현재 탭의 sessionStorage에 보관하며, 아이디 기억하기를 선택한 경우에만 아이디를 localStorage에 저장합니다.

## 명함 공유와 다운로드

1. 공개할 정보와 사진을 선택하고 **명함 만들고 공유하기**를 누릅니다.
2. 만들어진 링크를 복사하거나 QR 코드를 보여줍니다. QR 이미지도 저장할 수 있습니다.
3. 받는 사람은 로그인 없이 명함을 열고 **명함 이미지 저장(PNG)** 또는 **연락처 저장(VCF)**을 누릅니다. 사용자 정의 항목은 연락처 메모에 포함됩니다.

공유 명함은 이 PC의 `data/cards/`에 저장됩니다. 선택하지 않은 항목과 숨긴 이름은 저장하거나 공유하지 않습니다. 사진은 공유 명함과 PNG 이미지에 포함되며, VCF에는 텍스트 정보만 담깁니다. 공유 시점의 고정된 사본이므로 이후 수정한 내용은 새 명함을 만들어 공유해야 합니다. 서버 재시작 후에도 파일이 남아 있으면 명함을 열 수 있습니다.

외부 업로드나 배포는 없습니다. 서버는 같은 Wi-Fi 기기에서도 접속하도록 `0.0.0.0`에 바인딩합니다. 공유 주소에는 PC의 네트워크 IP를 사용하므로 **같은 Wi-Fi 연결과 실행 중인 서버가 필요**합니다. 네트워크가 여러 개면 공유 화면에서 실제 Wi-Fi 어댑터를 선택하세요. Windows 방화벽이나 공유기의 기기 간 통신 제한 때문에 접속이 안 될 수 있습니다. 앱은 방화벽 설정을 자동 변경하지 않습니다. IP나 실행 포트가 바뀌면 기존 링크의 주소도 바뀌므로 새 주소로 공유하세요. 외부 인터넷 공유에는 별도로 승인한 호스팅이 필요합니다.

## 검증

`npm run check` 및 `npm test`

API 저장/읽기, 서버 재시작 후 유지, 선택 항목 필터링, QR PNG 생성과 링크 일치, 잘못된 요청, VCF 한글/줄바꿈 처리, 이미지 텍스트 줄바꿈을 검증합니다. 실제 휴대폰 QR 스캔과 브라우저 다운로드는 자동 테스트에 포함되지 않습니다.

- https://toss.im — 한국어 서비스의 명확한 정보 전달 참고

외부 폰트를 불러오지 못하면 시스템 sans-serif 폰트로 표시합니다. WebMCP 읽기 기능은 지원 환경에서만 등록되며, 이 환경에서는 실제 WebMCP 실행을 검증하지 않았습니다.

## 이번 추가 기능

명함함(브라우저 로컬 저장), 분류 탭, 프리셋 편집, 이름/닉네임 선택, 사진 모양·크기, 가입 후 받은 명함 자동 저장, 다크모드, 한국어·영어 설정을 지원합니다. 명함함은 계정별 서버 저장이나 기기 간 동기화가 아닙니다. OCR는 추후 진행합니다. 기존 데이터 호환을 위해 내부 fold-* 저장 키는 유지합니다.

## 디자인 검토

서버 실행 후 **/mockup.html**에서 전체 디자인 변경안을 확인할 수 있습니다. 데스크톱/모바일과 라이트/다크 화면, 내 명함과 명함함을 전환할 수 있습니다. 목업은 실제 명함을 저장하지 않습니다. 승인한 전체 레이아웃을 실제 앱에 적용했습니다. /mockup.html은 기존 디자인 참고본으로 남겨 두었습니다.

제공한 DamDa_Logo.png를 헤더 및 브라우저 아이콘에 사용합니다. 상세 내역은 CHANGELOG-task.md에 기록했습니다.

## 적용된 워크스페이스 디자인

로그인 후 사이드 메뉴에서 내 명함과 명함함을 전환합니다. 프로필 사진 편집, 공개 정보, 프리셋 관리, 실시간 미리보기와 공유를 새 레이아웃에서 이용할 수 있습니다. 상단 **명함 저장하고 공유**는 공유 사본을 서버에 만들고 브라우저 명함함에 보관한 뒤 QR와 링크를 표시합니다. 새 프로필은 담다 블루 디자인으로 시작하며 기존 저장된 테마는 유지합니다. 모바일에서는 미리보기가 먼저 나오고 편집 영역이 이어집니다.

## 프리셋과 애니메이션

공개 정보 프리셋 영역의 **+ 프리셋 추가** 또는 각 프리셋 옆 **편집·삭제**를 사용합니다. 편집 폼에서 이름과 공개 항목을 직접 정한 뒤 **저장하고 적용**합니다. 프리셋을 삭제해도 현재 프로필과 저장한 명함은 삭제하지 않습니다.

화면 상단 **애니메이션 → 애니메이션 줄이기**로 이동 효과를 끌 수 있습니다. 기본값은 시스템 설정이며, 운영체제에서 동작 줄이기를 사용하면 앱에서도 효과를 줄입니다.


### 명함 스튜디오 UI

설정 버튼에서 화면 모드·언어·애니메이션을 선택합니다. 사진 모양·크기, 공개 이름, 명함함 분류와 프리셋 편집은 드롭다운 없이 선택 버튼으로 조작합니다.

명함을 마우스나 터치로 드래그하거나 방향키로 회전할 수 있습니다. 앞면·뒷면·회전 초기화 버튼도 제공됩니다. 뒷면 제목(60자), 문구(240자), 배경색과 패턴은 프로필 및 공유 명함에 함께 저장됩니다. 기존 PNG 저장은 앞면 이미지입니다.

검증: npm run check, npm test, npm run test:browser. 브라우저 테스트는 설치된 Microsoft Edge를 기본 사용하며 DAMDA_BROWSER_CHANNEL로 Playwright 채널을 지정할 수 있습니다. 브라우저 테스트는 임시 저장소와 임의 포트를 사용하고 테스트 후 종료합니다.
